## 功能

- **写入光标处**。可选「流式输入」或「整句写入」，边说边分批写入，或停录后一次写入。中途换了输入位置，剩余转写会留在气泡里，供你重新写入或复制。
- **离线转写**。麦克风录音在本机识别，断网也能听写。
- **边说边看**。点击浮窗上的气泡，可以查看正在生成的文字。
- **自定义浮窗**。拖动头像或声波可移动浮窗。拖到左侧、右侧或屏幕顶部后，浮窗可以自动收起，收起后仍可录音和停录。可在设置里调整贴边行为、头像、配色和听写快捷键。
- **应用内更新**。EchoBuddy 会在后台检查新版，也可以在设置里手动检查。下载完成后，由你确认重启安装。

## 安装与使用

1. 打开上方的发布页，在所需版本的 **Assets** 中下载 `EchoBuddy-Setup-<版本>-x64.exe`，运行安装向导。
2. 打开 EchoBuddy，把光标放在要输入的地方。点浮窗右侧的麦克风，或按默认快捷键 `Ctrl+Alt+M` 开始听写。
3. 说完后，再点一次按钮或按同一个快捷键结束听写。

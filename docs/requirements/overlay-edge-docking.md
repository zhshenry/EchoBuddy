# EchoBuddy 浮窗靠边收起方案

## 采用第 3 稿

浮窗拖到屏幕左侧、右侧或顶部后，可以收成紧凑控件。左右两侧竖排，顶部横排。待机时可以直接点麦克风，录音时显示计时和停止按钮。点头像可在录音中打开完整工具条。

## 高保真稿

| 图稿 | 收起后怎么用 | 取舍 |
| --- | --- | --- |
| 第 1 稿 · 点击展开 | 保留头像和向内的箭头，点击恢复完整浮窗。 | 入口小，操作前先展开。 [查看高保真](../../design/edge-docking/click-to-expand.png) |
| 第 2 稿 · 悬停展开 | 留一条浅珊瑚色细签，鼠标停留后展开。 | 少一步点击，鼠标经过屏边时更容易触发展开。 [查看高保真](../../design/edge-docking/hover-to-expand.png) |
| 第 3 稿 · 紧凑录音 | 保留麦克风和停录按钮，点头像展开。 | 收起后仍能操作听写。 [侧边高保真](../../design/edge-docking/compact-recording.png) · [顶部高保真](../../design/edge-docking/compact-recording-top.png) |

## 停靠与展开

| 动作 | 界面反应 |
| --- | --- |
| 拖动头像或声波靠边松手 | 浮窗的可见外壳距左、右或上边缘约 24 个逻辑像素时吸附。侧边保留松手时的高度，顶部保留横向位置。 |
| 指针移出停靠的浮窗 | 约 300 毫秒后收起。移回浮窗可取消计时。录音期间也能收起。 |
| 点击头像或待机时的箭头 | 从同一停靠位置展开并保持显示。右侧向左、左侧向右、顶部向下。指针从工具条外移入，再移出时才开始计时。 |
| 调整位置或解除停靠 | 收起时可按住栏身、头像、展开箭头或录音按钮拖动，沿边移动后保持收起。单击头像、箭头和录音按钮仍执行对应动作。展开时可拖动头像或声波。松手时距原边超过约 48 个逻辑像素，且未碰到另一侧的吸附范围，就恢复自由浮动。 |
| 从托盘显示浮窗 | 展开工具条。等指针先进入工具条，再按离开规则收起。 |

左右两侧的紧凑控件为 **44 × 110 个逻辑像素**，顶部为 **144 × 44 个逻辑像素**。贴屏的一边平齐，朝屏幕内的一边留圆角。麦克风和停止按钮占同一个 32 × 32 的位置。录音时以浅色底、红点和计时提示状态。 [EchoBuddy UI 设计规范](../../DESIGN.md)

收起和展开以停靠边缘为起点，浮窗轮廓在约 260 毫秒内弯曲过渡。系统启用「减少动态效果」时直接切换。

「更多设置 → 个性化」提供「贴边自动收起」的「是／否」选项。默认选「是」，由主动拖拽松手触发停靠。选「否」时从当前位置展开并解除停靠。

## 听写与待处理内容

| 场景 | 界面反应 |
| --- | --- |
| 紧凑控件待机或录音中 | 点击红色按钮或按听写快捷键，可以直接开始或停止。展开和收起使用同一个听写会话，计时连续。 |
| 准备和转写 | 在中间区域显示「准备中」或「转写中」。 |
| 设置、语言气泡或转写打开 | 保持完整工具条，便于继续操作。 |
| 音频处理需要用户留意 | 自动展开显示提示。有待处理文字时打开「本次转写」，提供写入和复制入口。 |

## 显示器与位置

- 以松手时浮窗所在屏幕的工作区为边界，留出任务栏。
- 保存显示器、停靠方向及沿边位置。重启后恢复为紧凑控件。自由浮动时保存完整位置。
- 停靠的显示器移除时迁回主屏同侧。缩放、分辨率或任务栏位置变化时重新按工作区定位。
- 收起、展开在同一个透明窗口内完成。收起后只有紧凑控件占用鼠标命中区域，周围应用仍可点击。切换布局与启动听写时沿用不抢焦点的窗口行为。 [现有浮窗定位](../../electron/overlay.ts)

## 验收

1. 验证左、右、顶部三侧吸附，拖离后恢复自由浮动。重启后恢复同一侧与同一位置。
2. 对照图稿检查待机与录音的窗口尺寸、头像、箭头、计时和开始停止按钮。收起后周围区域可以继续点击。
3. 用隔离测试实例验证收起时开录、展开后计时连续、重新收起后仍可停录，以及待处理文字的恢复入口。
4. 检查三侧收起时首尾画面是否连续，收起后点击原工具条范围内的空白处应落到背后的窗口。
